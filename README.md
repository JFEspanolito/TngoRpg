
# TngoRPG

Bienvenido a **TngoRPG**, un proyecto desarrollado con **RPG Maker VX Ace**.

Este repositorio contiene la versión jugable del mini RPG "El niño del palo" un RPG experimental donde aprendí a usar RPG Maker creando una historia 100% ambientada en la comunidad del The New Game Order, y todas nuestras aventuras, cotorreos y chistes internos.

---

## 🎮 Para jugadores

### Instalación y ejecución

1. Descarga y descomprime el archivo `TngoRpg.zip`.
2. Dentro encontrarás el ejecutable:

   ```
   TngoRpg.exe
   ```
3. **Requisito previo obligatorio**: instala el **RPG Maker VX Ace Run Time Package (RTP)**, disponible en la página oficial:
   👉 [Descargar RTP](https://www.rpgmakerweb.com//run-time-package)
4. Una vez instalado el RTP, ejecuta `TngoRpg.exe` para comenzar a jugar.

### Notas

* Si al iniciar el juego aparece un error de recursos faltantes, asegúrate de haber instalado correctamente el RTP.
* El juego no requiere instalación adicional; basta con descomprimir y ejecutar.
